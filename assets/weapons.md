> **Critérios**: Gratuito • Uso comercial permitido • Licença livre/permissiva verificável (CC0, CC BY, CC BY-SA, Domínio Público, GPL) • URL funcional.

## Como usar / baixar em massa

### game-icons.net (ZIPs por tag)
```bash
# Weapon geral
wget https://game-icons.net/archives/ffffff/000000/weapon.svg.zip
wget https://game-icons.net/archives/ffffff/000000/weapon.png.zip

# Blades
wget https://game-icons.net/archives/ffffff/000000/blade.svg.zip

# Guns
wget https://game-icons.net/archives/ffffff/000000/gun.svg.zip

# Arrows
wget https://game-icons.net/archives/ffffff/000000/arrow.svg.zip

# Axes
wget https://game-icons.net/archives/ffffff/000000/axe.svg.zip

# Bombs
wget https://game-icons.net/archives/ffffff/000000/bomb.svg.zip

# Explosions
wget https://game-icons.net/archives/ffffff/000000/explosion.svg.zip

# Ninja
wget https://game-icons.net/archives/ffffff/000000/ninja.svg.zip
```

### freegameassets.com
Cada página de categoria tem botão "Download" para ZIP completo do pack.

### Kenney.nl
Botão "Download" em cada página de asset, ou bundle All-in-1: https://kenney.itch.io/kenney-game-assets

### OpenGameArt
Botão "File(s)" em cada página — baixe o `.zip` ou `.png` direto.

### Openclipart
Botão "Download SVG" em cada item, ou use API: `https://openclipart.org/api/search/json?query=<termo>`

| **GPL 2.0 / 3.0** | ✅ | ✅ (código fonte) | ✅ | ✅ (mesma licença) |
| **OGA-BY 3.0** | ✅ | ✅ Obrigatória | ✅ | ✅ |
