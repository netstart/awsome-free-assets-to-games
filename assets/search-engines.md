Cada entrada inclui: nome, URL, região/idioma predominante, foco (geral / privacidade / regional), e observações sobre uso para pesquisa de assets.

## Como usar estes sites para encontrar novos assets gratuitos

1. **Busca por domínio/fonte**: `site:itch.io "free" "CC0" game assets`
2. **Busca por tipo de asset**: `free pixel art tileset CC0 commercial use`
3. **Busca por licença**: `game assets "Creative Commons Zero" OR "CC0" OR "OFL" free download`
4. **Busca regional**: usar Baidu para assets chineses, Yandex para russos, Naver/Daum para coreanos
5. **Busca por privacidade**: DuckDuckGo, Brave Search, StartPage, Swisscows, Qwant evitam bolha de filtro
