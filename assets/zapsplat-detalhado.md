## ✅ Como verificar licença de cada som (passo a passo)

1. Acesse a página do som no ZapSplat
2. Confirme se está na seção gratuita (Basic User) ou premium
3. Confirme que a licença permite uso comercial (Standard License permite)
4. Para conta gratuita: **atribuição é obrigatória** — anote o autor e formate o crédito conforme https://www.zapsplat.com/how-to-credit-us/
5. Registre a URL e licença no arquivo correspondente na pasta `assets/`
