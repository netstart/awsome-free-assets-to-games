# Freesound.org — Banco colaborativo de sons gratuitos (pesquisa 23/10/2026)

Critério (AGENTS.md): gratuito + uso comercial permitido + licença verificável na página oficial.

Licença oficial verificada: https://freesound.org/help/faq/#licenses — três licenças disponíveis (CC0, CC BY, CC BY-NC). **Apenas sons com CC0 e CC BY atendem ao critério de uso comercial**. CC BY-NC NÃO permite uso comercial. ✅ CC0 = domínio público (uso livre, sem atribuição obrigatória); CC BY = uso comercial com atribuição obrigatória.

## Como filtrar para uso comercial

- CC0 (domínio público): https://freesound.org/search/?license=cc0
- CC BY (atribuição obrigatória, comercial OK): https://freesound.org/search/?license=attribution
- Evitar: CC BY-NC (não comercial)
