> **Uso 3D/2.5D:** Modelos 3D low-poly podem ser usados diretamente (jogo 3D) ou pré-renderizados em sprites 2D/2.5D (estilo Dixit, Donkey Kong Country, Octopath Traveler). Texturas servem para fundo de cartas, card backs, tabelas e tabuleiro.

## Sobre a Poly Haven

Biblioteca pública de assets 3D (modelos, texturas, HDRIs). Todos os assets são liberados sob licença CC0. Disponibiliza API pública JSON para listagem completa:
- Modelos: https://api.polyhaven.com/assets?type=models
- Texturas: https://api.polyhaven.com/assets?type=textures

Cada modelo inclui: nome, categoria, tags, polycount, resolução máxima, dimensões, formato de download (GLB, FBX, OBJ, blend, etc.) e thumbnail.
