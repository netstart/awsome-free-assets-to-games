## ✅ Como verificar licença de cada som (passo a passo)

1. Acesse a página do som no FreeSFX
2. Localize a licença exibida
3. Confirme que permite uso comercial
4. Anote requisitos de atribuição
5. Registre a URL e licença no arquivo correspondente na pasta `assets/`
