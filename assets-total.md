# Assets — Hyakki

Índice mestre de fontes de assets gratuitos para uso comercial no projeto.

Todos os assets listados devem ser:
1. **Gratuitos** (zero custo)
2. **Livres para uso comercial**
3. **De licença livre/permissiva** (CC0, CC BY, CC BY-SA, OFL, MIT, Apache 2.0, Zlib, Domínio Público ou equivalente)

Antes de adicionar qualquer novo asset, verifique a licença oficial na página de origem e registre a URL e a licença no arquivo correspondente.
